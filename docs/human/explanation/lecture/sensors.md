# 센서

AMR의 인지 단계에서 사용하는 센서의 원리와 특징을 정리한 문서입니다. 원본은 강의 자료 슬라이드 9~17입니다.

## 센서 입력 종류

슬라이드 9는 자율주행 로봇에 장착하는 센서 10종을 제시합니다.

| 분류 | 센서 |
|---|---|
| 거리·환경 인식 | LiDAR, Radar, Sonar, Ultrasonic |
| 영상 | 카메라, 조도센서 |
| 자세·위치 | IMU, GNSS |
| 주행량 | Wheel Encoder |
| 접촉 | 촉각센서 |

## LiDAR

LiDAR는 Light Detection and Ranging의 약자입니다. 레이저로 거리를 측정하고 회전 스캔으로 주변 거리 분포를 수집합니다(슬라이드 10~11). 슬라이드 11의 예시 제품은 수평 시야각 270°의 2D LiDAR이며 모델별 최대 측정 거리는 5 m, 10 m, 20 m입니다.

활용 분야는 자율주행 차량, 로봇·드론, 지형 측량, 안전 관리입니다(슬라이드 12).

### 2D LiDAR와 3D LiDAR 비교

| 구분 | 2D LiDAR | 3D LiDAR |
|---|---|---|
| 스캔 방식 | 수평선 1개로 레이저 스캔 | 수평 레이저 여러 채널(16, 32, 128채널) |
| 데이터 형태 | (x, y) 좌표 | 3차원 Point Cloud, Voxel |
| 용도 | 2D 지도 작성, 장애물 회피, 위치 추정 | 야외 자율주행, 객체 인식, 정밀 측량, 3D 모델링 |

### LiDAR 데이터 구조

LiDAR 1회 스캔 데이터에는 다음 10개 항목이 있습니다(슬라이드 14).

| 항목 | 의미 |
|---|---|
| 최소 각도, 최대 각도 | 스캔 시작·종료 각도 |
| 해상도 | 인접 측정 사이 각도 간격 |
| 최소 거리, 최대 거리 | 유효 측정 범위 |
| 측정 개수 | 1회 스캔의 측정 점 수 |
| 회전 주기 | 1회전에 걸리는 시간 |
| 샘플링 주기 | 측정 점 사이 시간 간격 |
| 측정 값(거리) | 각 방향의 거리 |
| 측정 값(강도) | 각 방향의 반사 강도 |

`controllers/tb3_lidar/tb3_lidar.py`는 TurtleBot3의 LDS-01 LiDAR 값을 `getRangeImage()`로 읽습니다. 이 코드는 `ranges[180]`을 전방, `ranges[0]`을 후방, `ranges[90]`을 좌측, `ranges[270]`을 우측 거리로 출력합니다.

## IMU

IMU(Inertial Measurement Unit)의 측정 방식은 다음과 같습니다(슬라이드 15).

- 가속도계와 자이로로 선형 가속도와 각속도를 측정함
- 높은 주기로 자세·운동 상태를 추정할 수 있으나 시간에 따라 drift가 발생함
- 자력계로 지구 자기장을 측정해 방향 정보를 추정함

## GNSS

GNSS(Global Navigation Satellite System)의 특징은 다음과 같습니다(슬라이드 16).

- 위성 신호로 절대 위치와 속도를 제공함
- 장시간 사용해도 drift가 적어 전역 좌표계 기준 위치 보정에 유리함
- 건물·터널·지하 공간에서는 신호 차단과 정확도 저하가 발생함

## Wheel Encoder

Wheel Encoder의 특징은 다음과 같습니다(슬라이드 17).

- 바퀴 회전량으로 주행 거리와 속도를 추정함
- 저속 주행에서도 비교적 안정적인 이동 정보를 제공함
- 타이어 슬립이나 미끄러짐이 발생하면 누적 오차가 증가함

Encoder 값으로 로봇 위치를 계산하는 방법은 [SLAM의 Wheel Odometry](slam.md#wheel-odometry)에 있습니다.
